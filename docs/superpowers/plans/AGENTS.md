# Working in docs/superpowers/plans/

- One plan file per milestone or feature, named `YYYY-MM-DD-<feature-name>.md`, written in Simplified Chinese (the superpowers header template stays in English).
- Plans follow the writing-plans skill format: header (goal/architecture/tech stack/spec), Global Constraints, Review Focus, tasks with TDD steps and checkboxes.
- A plan is executed only after the user reviews and approves it. Check off `- [x]` steps as they complete; do not rewrite history in the plan — deviations are noted in the task's step.
