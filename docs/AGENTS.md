# Working in docs/

- All documents in this directory are written in Simplified Chinese.
- Every design proposal not yet confirmed by the user must be marked with 【建议】or listed in the "待确认问题" section of its document.
- When a discussion changes a decision, update the affected document in place; keep documents consistent with each other (01 defines requirements, 02 architecture, 03 orchestration details, 04 milestones).
- Do not start implementation code from these documents until the user confirms the corresponding sections.
- When code is created under `packages/`, add links from these documents to the implementing package's README.md.
