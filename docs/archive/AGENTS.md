# Working in docs/archive/

- These are the archived design-discussion documents; `docs/PRD.md` is the authoritative summary. When a decision changes, update the affected section here first, then sync `docs/PRD.md`.
- Documents are written in Simplified Chinese.
- New unconfirmed proposals must be marked with 【建议】; confirmed decisions are recorded in the "已确认决议记录" section of each document.
