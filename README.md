# hotpot-code

基于 Node + TypeScript 的 code agent。目标：更低的成本、更好的效果。

## 目录结构

```
├── AGENTS.md          # 开发约定（英文）
├── AGENTS_zh-CN.md    # 开发约定（中文备份）
├── docs/              # 项目文档（md 即代码）
│   ├── PRD.md         # 定稿产品需求文档（权威需求来源）
│   ├── archive/       # 设计探讨归档：需求/架构/编排/里程碑
│   └── superpowers/   # 实现计划
└── packages/          # 代码（M1 启动后创建）
```
