# Working in src/tools/

- `ToolDefinition<T>` binds its generic to the zod schema: `parameters: z.ZodType<T>`. `register` erases `T` to `unknown` and wraps `execute`/`present` with `schema.parse`, so untrusted LLM input is validated and stripped before the tool body sees it.
- `declarations()` converts schemas with zod v4's built-in `z.toJSONSchema` (pinned by controller ruling; never add zod-to-json-schema). The top-level schema must be `type: "object"`; anything else throws.
- The declaration `description` always comes from the tool definition field, not from a schema-level `.describe()`.
- `zod` (^4) is the only whitelisted runtime dependency here besides `@hotpot/ai`.
- `bash.ts` implements `bashTool`: runs commands via `bash -c`, and `content` combines stdout, stderr and the exit code. Each stream is truncated to its last `MAX_OUTPUT_CHARS` (30000) characters with a notice at the top of `content`. Commands matching `DANGEROUS_COMMAND_PATTERNS` must pass `ApprovalChain.ask({kind: "command"})` before spawning — a deny returns `isError` without executing. The rm rule matches recursive deletion in any flag order (`-rf`, `-fr`, `-R`, `-frv`) and the long option `--recursive`; the device-write rule excludes safe pseudo-devices (`/dev/null`, `/dev/stdout`, `/dev/stderr`, `/dev/tty`, `/dev/zero`, `/dev/random`, `/dev/urandom`) so `2>/dev/null` never asks for approval. The child runs detached in its own process group: timeout (default 120s, overridable per call via `timeoutMs`) and `AbortSignal` SIGKILL the whole group, including background descendants. The call settles when the direct `bash -c` exits (a short drain window, then the inherited stdio pipes are released), so `nohup ... &` daemons do not hang the turn. `isConcurrencySafe: false`; extend the pattern table by editing the exported constant only.
- `read.ts` implements `readTool`: reads a text file (path resolved against `ctx.cwd`) and returns lines as `line<TAB>content` with 1-based numbering. `offset` (default 1) and `limit` (default `READ_DEFAULT_LIMIT` 2000) page through the file; when more lines remain, a `[truncated: ...]` notice with the next offset is appended. Files containing NUL bytes are rejected as binary; missing files return `isError` instead of throwing. `isConcurrencySafe: true`.
- `write.ts` implements `writeTool`: writes `content`, creating parent directories recursively. If the target already exists it must pass `ApprovalChain.ask({kind: "write"})` first — a deny returns `isError` without writing. `isConcurrencySafe: false`.
- `edit.ts` implements `editTool`: exact string replacement (no regex), utf8 round-trip so CRLF files keep their `\r`. The replacement goes through a function replacer, so `$` patterns in `new_string` (`$$`, `$&`, `` $` ``, `$'`) are written verbatim, never expanded. Zero occurrences of `old_string` → `isError` advising to read the file first; multiple occurrences without `replace_all` → `isError` with the occurrence count; `replace_all: true` replaces all. `isConcurrencySafe: false`.
- Erasable TypeScript only, `.ts` extension on relative imports, no `any`, no inline imports; comments in Simplified Chinese.
- Verify with `pnpm test` and `pnpm exec biome check` from the repo root before committing.
